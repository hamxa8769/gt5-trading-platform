## 📱 API TESTING

Want to test the API directly?

```bash
# Login
TOKEN=$(curl -s -X POST http://localhost:3000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"demo@gt5trading.com","password":"Demo123!"}' \
  | jq -r '.access_token')

# Place a trade
curl -X POST http://localhost:3000/api/v1/trading/orders \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "instrument_id": 1,
    "order_type": "market",
    "side": "buy",
    "quantity": 1
  }' | jq

# Get analytics
curl http://localhost:3000/api/v1/trading/analytics \
  -H "Authorization: Bearer $TOKEN" | jq

# Get trade history  
curl http://localhost:3000/api/v1/trading/history \
  -H "Authorization: Bearer $TOKEN" | jq
```
